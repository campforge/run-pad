# MdRun (`.inv`)

**MdRun** is an open, human-readable format for executable documents, stored as `.inv` files.

An MdRun document combines documentation, source code and execution metadata into a single text file. The format is language-neutral and is designed to be simple to read, easy to edit and friendly to version control systems.

Although the first implementation targets the .NET ecosystem, the format itself is intentionally independent of any programming language or runtime.

---

## Philosophy

MdRun is built around a few simple ideas.

### Human First

An MdRun document should be understandable without specialized tools.

Open it in any Markdown editor and it remains a readable document.

---

### Open Format

MdRun is based on existing standards:

* Markdown
* YAML Front Matter

No binary data.

No proprietary serialization.

No hidden metadata.

---

### Executable Documentation

Documentation and source code belong together.

A document explains *what* the code does, while the embedded source demonstrates *how* it works.

---

### Minimal Ceremony

An author should write only the meaningful code.

Boilerplate generated by the runtime should never appear in the document.

For example, a `Program` document contains only the program itself—not the surrounding project structure, generated files or unnecessary wrappers.

---

### Language Neutral

The format is not tied to any programming language.

Current implementation:

* C#

Possible future implementations:

* Java
* Kotlin
* Python
* JavaScript
* Go
* Rust

---

## Document Structure

Every document consists of two parts.

1. YAML Front Matter
2. Markdown Content

````text
┌───────────────────────────┐
│ YAML Front Matter         │
├───────────────────────────┤
│ Markdown                  │
│                           │
│  ## Program               │
│                           │
│  ```language run          │
│  ...                      │
│  ```                      │
└───────────────────────────┘
````

---

## Front Matter

```yaml
---
version: "1.0"

language: csharp

targetSdk: latest

kind: Statements

packages:
  Dapper: 2.1.66

references:
  - ../Shared/Shared.csproj

namespaces:
  - System
  - System.Linq
---
```

| Property     | Description                               |
| ------------ | ----------------------------------------- |
| `version`    | Document format version                   |
| `language`   | Programming language                      |
| `targetSdk`  | Runtime or SDK version                    |
| `kind`       | Compilation model                         |
| `packages`   | External package dependencies             |
| `references` | Project or assembly references            |
| `namespaces` | Global namespaces imported by the runtime |

## Code Blocks

Executable code is stored inside standard fenced Markdown blocks.

````markdown
## Program

```csharp run
void Main()
{
    Say("Hello");
}

void Say(string msg)
{
    Console.WriteLine();
}
```
````

The `run` attribute identifies the executable entry point.

Everything outside executable blocks is ordinary Markdown.

---

## Compilation Models

### Statements

Top-level statements.

```csharp
var message = "Hello";
Console.WriteLine(message);
```

---

### Program

Explicit entry point without surrounding boilerplate.

```csharp
void Main()
{
    Say("Hello");
}

void Say(sting message)
{
    Console.WriteLine();
}
```

The runtime supplies the surrounding infrastructure required by the target platform.

---

### Expression

A single expression whose value becomes the execution result.

```csharp
DateTime.Now
```
